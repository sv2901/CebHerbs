# CEB Herbs - Premium Botanical Website PRD

## Project Overview
**Company:** Cutting Edge Botanical Pvt. Ltd.
**Brand:** CEB Herbs
**Domain:** cebherbs.com
**Type:** Static Marketing Website for Lead Generation

## User Personas
1. **B2B Bulk Buyers** - Wholesale businesses seeking herbs/spices suppliers
2. **Wellness Brands** - Companies looking for botanical ingredients
3. **International Importers** - Global businesses seeking export-quality products
4. **Herbal Product Manufacturers** - Businesses needing raw botanical materials

## Core Requirements (Static)
- Premium botanical luxury aesthetic with light theme
- WhatsApp as primary contact method (+91 9711058451)
- Mobile responsive design
- SEO optimized
- Deployable to Vercel
